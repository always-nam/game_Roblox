# 틸트 구슬판 (Tilt Marble Board)

판을 기울여 색 구슬을 같은 색 구멍에 넣는 HTML5/JavaScript 퍼즐 게임입니다. 설치 없이 PC와 모바일 브라우저에서 실행됩니다.

**▶ 플레이: https://always-nam.github.io/game_Roblox/** (단일 파일 버전: [single.html](https://always-nam.github.io/game_Roblox/single.html))

## 규칙

- 판을 **위·아래·왼쪽·오른쪽**으로 기울이면 판 위의 모든 구슬과 돌이 **한꺼번에** 벽이나 다른 조각에 막힐 때까지 굴러갑니다.
- **구슬**은 같은 색 구멍을 지나가는 순간 빠집니다. 다른 색 구멍은 그냥 지나칩니다. 구멍 하나에는 구슬 하나만 들어가고, 채워진 구멍은 평평한 바닥이 됩니다.
- **회색 돌**은 구멍에 빠지지 않아 멈춤판 역할을 합니다. 돌이 **검은 함정**에 들어가면 함정이 메워져 바닥이 됩니다.
- 구슬이 **검은 함정**에 빠지면 실패입니다. 되돌리기로 한 수씩 취소할 수 있습니다.
- 모든 구슬을 구멍에 넣으면 성공입니다. 최소 이동 수(풀이기로 계산)와 비교해 별 1~3개를 받습니다.

16개 단계(1~6단계는 규칙 소개)와 날짜마다 바뀌는 **오늘의 퍼즐**(시드 기반 자동 생성, 풀이 가능 여부를 미리 검증)이 있습니다.

## 조작

| 환경 | 기울이기 | 되돌리기 | 처음부터 |
|---|---|---|---|
| PC | 방향키 또는 WASD | Z / U / Backspace | R |
| 모바일 | 판 위에서 스와이프, 또는 [기울기 조작]을 켜고 휴대폰을 직접 기울이기 | 버튼 | 버튼 |
| 공통 | 화면의 방향 버튼 | 버튼 | 버튼 |

**휴대폰 기울기 조작**: 켤 때 든 각도를 수평 기준으로 삼고, 약 14° 이상 기울이면 그 방향으로 한 번 기울입니다. 같은 방향으로 다시 기울이려면 6° 이내로 되돌아와야 합니다. 휴대폰을 거의 세워 들어도(세로를 지나도) 네 방향이 모두 동작하도록, 센서 각도를 중력 방향으로 바꿔 계산합니다. 화면 오른쪽 위 **수평계**의 점이 고리 밖으로 나가면 기울어지고, 수평계를 누르면 지금 각도를 새 기준으로 잡습니다. 기준 근처의 느린 자세 변화에는 기준이 천천히 따라옵니다. iPhone(iOS 13 이상)은 처음 켤 때 동작 및 방향 접근 권한을 묻습니다. 주소 끝에 `#debug`를 붙이면 센서 원래 값이 화면에 표시됩니다.

**전체 화면**: 게임 화면 오른쪽 위 버튼으로 브라우저 주소창 없이 크게 볼 수 있습니다(Android·PC 지원, iPhone Safari는 브라우저가 지원하지 않아 버튼이 숨겨지며 "홈 화면에 추가"로 설치하면 전체 화면으로 실행됩니다). 판은 화면 크기에 맞춰 최대한 크게 그려지고, 가로나 넓은 화면(폴드 펼침·태블릿·PC)에서는 판이 왼쪽, 조작부가 오른쪽에 놓입니다.

**앱처럼 설치**: 휴대폰 브라우저에서 사이트를 연 뒤 "홈 화면에 추가"(iPhone Safari: 공유 → 홈 화면에 추가 / Android Chrome: 메뉴 → 앱 설치)를 누르면 앱처럼 설치되고, 한 번 연 뒤에는 인터넷 없이도 실행됩니다.

진행 상황(단계별 최고 기록)은 브라우저 `localStorage`에 저장됩니다. 저장이 막힌 환경에서도 게임은 동작합니다.

## 실행

```bash
npm install
npm start            # http://localhost:8080 에서 실행
npm run build        # dist/tilt-marble.html: CSS·JS를 모두 넣은 단일 파일
```

`dist/tilt-marble.html`은 파일을 더블클릭해 바로 열 수도 있습니다.

## 테스트

```bash
npm run test:unit    # 게임 로직·레벨 풀이 가능성·생성기 (Node 내장 테스트)
npm test             # 단위 테스트 + 빌드 + Playwright 브라우저 테스트(데스크톱·모바일)
npm run test:live    # 배포된 사이트 대상 브라우저 테스트
```

- 단위 테스트는 모든 단계를 너비 우선 탐색 풀이기로 풀어 **풀 수 있는지**와 **최소 이동 수(par)**를 검증합니다.
- 브라우저 테스트는 키보드·방향 버튼·스와이프 입력, 실패/되돌리기, 16단계 전체 클리어, 화면 넘침, 저장소 차단 상황을 확인합니다.

## 구조

```
index.html          화면 구조
style.css           디자인
src/engine.js       순수 게임 로직(기울이기, 승패 판정, 풀이기)
src/levels.js       16개 단계 데이터
src/generator.js    시드 기반 퍼즐 생성기(오늘의 퍼즐)
src/motion.js       휴대폰 기울기 → 방향 변환(중력 방향 기반, 순수 로직)
manifest.webmanifest, sw.js, icons/   앱 설치(PWA)·오프라인 실행
scripts/make-icons.py  앱 아이콘 생성
src/main.js         화면 그리기, 애니메이션, 입력 처리
scripts/build.mjs   단일 HTML 파일 빌드
scripts/curate.mjs  레벨 선별용 탐색 도구
tests/              단위 테스트(unit)·브라우저 테스트(e2e)
```

## 배포

GitHub Pages로 배포됩니다(`.github/workflows/deploy.yml`). 작업 브랜치에 push하면 단위 테스트를 거쳐 자동 배포됩니다.

배포된 사이트를 대상으로 브라우저 테스트를 실행하려면:

```bash
npm run test:live    # https://always-nam.github.io/game_Roblox/ 대상
```
