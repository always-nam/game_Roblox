# 틸트 구슬판 (Tilt Marble Board)

판을 기울여 색 구슬을 같은 색 구멍에 넣는 HTML5/JavaScript 퍼즐 게임입니다. 설치 없이 PC와 모바일 브라우저에서 실행됩니다.

**▶ 플레이: https://always-nam.github.io/game_Roblox/** (단일 파일 버전: [single.html](https://always-nam.github.io/game_Roblox/single.html))

## 규칙

- 판을 **위·아래·왼쪽·오른쪽**으로 기울이면 판 위의 모든 구슬과 돌이 **한꺼번에** 벽이나 다른 조각에 막힐 때까지 굴러갑니다.
- **색깔 문**(4장)은 같은 색 구슬만 지나갈 수 있고, 다른 구슬과 돌에게는 벽입니다.
- **구슬**은 같은 색 구멍을 지나가는 순간 빠집니다. 다른 색 구멍은 그냥 지나칩니다. 구멍 하나에는 구슬 하나만 들어가고, 채워진 구멍은 평평한 바닥이 됩니다.
- **회색 돌**은 구멍에 빠지지 않아 멈춤판 역할을 합니다. 돌이 **검은 함정**에 들어가면 함정이 메워져 바닥이 됩니다.
- 구슬이 **검은 함정**에 빠지면 실패입니다. 되돌리기로 한 수씩 취소할 수 있습니다.
- 모든 구슬을 구멍에 넣으면 성공입니다. 최소 이동 수(풀이기로 계산)와 비교해 별 1~3개를 받습니다.

## 스토리 모드 — 할아버지의 구슬 공방

여름방학, 하루는 시골 할머니 댁 다락방에서 '하루에게'라고 적힌 할아버지의 나무 상자를 찾습니다. 긴 여행을 떠난 할아버지는 구슬판과 함께 편지를 남겼습니다. "상자 속 판을 하나씩 풀어 보렴. 모두 풀면 마지막 판에서 만나자."

| 장 | 장소 · 배경 | 새로 나오는 것 | 장 끝 |
|---|---|---|---|
| 1장 다락방의 상자 | 다락방 · 여름 아침 (서까래, 둥근 창 햇살, 떠다니는 먼지) | 구슬·구멍·돌·함정 규칙 소개 | 첫 번째 편지 |
| 2장 여름 대청마루 | 대청마루 · 여름 저녁 (처마, 마루, 먼 산, 반딧불) | 더 큰 판, 함정 메우기 | 두 번째 편지 |
| 3장 가을 장터 | 장터 · 가을 해 질 녘 (노을, 천막, 등불 줄, 단풍잎) | 네 가지 색 | 세 번째 편지 |
| 4장 겨울 공방 | 공방 · 첫눈 오는 밤 (창밖 눈, 작업대, 난로 불빛, 눈) | **색깔 문**(같은 색 구슬만 통과) | 마지막 편지 → 결말 |

- 4장 × 8단계 = 32단계. 각 장의 첫 단계를 처음 열면 그 장의 이야기가, 마지막 단계를 풀면 할아버지 편지가 나옵니다. 앞 장을 마치면 다음 장이 열립니다.
- 배경은 이미지 파일 없이 SVG와 캔버스로 그리며(`src/scenery.js`), 장마다 판 바닥 색도 바뀝니다.
- 메뉴의 각 장에서 이야기와 편지를 다시 볼 수 있습니다. 이야기 장면은 화면을 누르거나 Enter로 넘기고, Esc로 건너뜁니다.
- 1~16단계는 기존 단계, 17~32단계는 `scripts/curate2.mjs`로 탐색해 선별했습니다. 모든 단계는 풀이기로 풀 수 있는지와 최소 이동 수를 검증합니다.

날짜마다 바뀌는 **오늘의 퍼즐**(시드 기반 자동 생성, 풀이 가능 여부를 미리 검증)도 있습니다.

## 조작

| 환경 | 기울이기 | 되돌리기 | 처음부터 |
|---|---|---|---|
| PC | 방향키 또는 WASD | Z / U / Backspace | R |
| 모바일 | 판 위에서 스와이프, 또는 [기울기 조작]을 켜고 휴대폰을 직접 기울이기 | 버튼 | 버튼 |
| 공통 | 화면의 방향 버튼 | 버튼 | 버튼 |

**휴대폰 기울기 조작**: [기울기 조작]을 켜면 기울이는 쪽으로 구슬이 **흘러갑니다**. **원점**: 좌우는 실제 수평(0°)이 원점이라, 오른쪽으로 기운 채 시작하면 실제 판처럼 바로 오른쪽으로 흐릅니다. 앞뒤는 사람마다 편하게 드는 각도가 달라, 처음 켰을 때 편한 각도로 들고 잠깐(0.3초) 멈추면 그 각도를 원점으로 저장합니다. 원점은 단계를 시작할 때마다 다시 잡지 않고 새로고침 뒤에도 유지되며, 오른쪽 위 **수평계**를 누르면 다시 잡습니다. 좌우 기울기는 쟁반을 기울인 각도로 재므로 휴대폰을 세워 들어도 감도가 같고(70°까지), 거의 세워 들었을 때는 핸들처럼 돌리면 됩니다. 정중앙으로 돌아올 필요 없이 기울인 방향을 바꾸면 바로 그 방향으로 이어서 움직이고(같은 방향은 이미 끝까지 굴러간 상태라 다시 적용하지 않음), **대각선**으로 기울이면 두 방향을 번갈아 적용해 더 움직이지 않을 때까지 굴러갑니다. 감도: 둔하게 18° · 보통 12° · 민감 8°. 되돌리기·처음부터 직후에는 판을 원점으로 돌릴 때까지 기울기 입력을 잠시 멈춥니다. iPhone(iOS 13 이상)은 처음 켤 때 동작 및 방향 접근 권한을 묻습니다. 주소 끝에 `#debug`를 붙이면 센서 원래 값이 화면에 표시됩니다.

**소리**: 음원 파일 없이 Web Audio API로 만든 효과음 — 굴러가는 소리(빨라질수록 커지고 높아짐, 칸 이음새를 지날 때 '톡'), 벽에 부딪히는 나무 소리, 구멍에 쏙 들어가는 소리, 함정에 빠지는 소리, 돌이 함정을 메우는 소리, 성공 차임(별 개수만큼), 실패음. Android에서는 부딪힐 때 짧게 진동합니다. 게임 화면 오른쪽 위 스피커 버튼(PC는 M 키)으로 켜고 끕니다. 브라우저 정책상 화면을 한 번 누른 뒤부터 소리가 납니다.

**구슬 움직임**: 실제 공처럼 멈춘 상태에서 출발해 점점 빨라지고(등가속, 걸리는 시간 ∝ √거리), 벽에 부딪히면 살짝 찌그러졌다가 튕겨 나온 뒤 멈춥니다. 구슬 표면 무늬는 굴러간 거리만큼 진행 방향으로 돌고 빛 반사는 제자리에 있습니다. 기울기 조작으로 연달아 흐를 때는 한 움직임이 끝난 뒤 0.26초 쉬고, 방향이 바뀌면 0.14초 기울어 있어야 움직입니다.

**전체 화면**: 게임 화면 오른쪽 위 버튼으로 브라우저 주소창 없이 크게 볼 수 있습니다(Android·PC 지원, iPhone Safari는 브라우저가 지원하지 않아 버튼이 숨겨지며 "홈 화면에 추가"로 설치하면 전체 화면으로 실행됩니다). 판은 화면 크기에 맞춰 최대한 크게 그려지고, 가로나 넓은 화면(폴드 펼침·태블릿·PC)에서는 판이 왼쪽, 조작부가 오른쪽에 놓입니다.

**앱처럼 설치**: 휴대폰 브라우저에서 사이트를 연 뒤 "홈 화면에 추가"(iPhone Safari: 공유 → 홈 화면에 추가 / Android Chrome: 메뉴 → 앱 설치)를 누르면 앱처럼 설치되고, 한 번 연 뒤에는 인터넷 없이도 실행됩니다.

진행 상황(단계별 최고 기록)은 브라우저 `localStorage`에 저장됩니다. 저장이 막힌 환경에서도 게임은 동작합니다.

## 실행

```bash
npm install
npm start            # http://localhost:8080 에서 실행
npm run build        # dist/tilt-marble.html: CSS·JS를 모두 넣은 단일 파일
```

`dist/tilt-marble.html`은 파일을 더블클릭해 바로 열 수도 있습니다.

## 테스트

```bash
npm run test:unit    # 게임 로직·레벨 풀이 가능성·생성기 (Node 내장 테스트)
npm test             # 단위 테스트 + 빌드 + Playwright 브라우저 테스트(데스크톱·모바일)
npm run test:live    # 배포된 사이트 대상 브라우저 테스트
```

- 단위 테스트는 모든 단계를 너비 우선 탐색 풀이기로 풀어 **풀 수 있는지**와 **최소 이동 수(par)**를 검증합니다.
- 브라우저 테스트는 키보드·방향 버튼·스와이프 입력, 실패/되돌리기, 16단계 전체 클리어, 화면 넘침, 저장소 차단 상황을 확인합니다.

## 구조

```
index.html          화면 구조
style.css           디자인
src/engine.js       순수 게임 로직(기울이기, 승패 판정, 풀이기)
src/levels.js       32개 단계 데이터(4장 × 8단계)
src/story.js        이야기 장면·할아버지 편지·결말 대본
src/scenery.js      장마다 바뀌는 배경(SVG 풍경 + 캔버스 효과)
src/generator.js    시드 기반 퍼즐 생성기(오늘의 퍼즐)
src/motion.js       휴대폰 기울기 → 방향 변환(기기 축 회전 기반, 순수 로직)
src/anim.js         구슬 굴러가기 연출 계산(등가속·튕김·무늬 회전)
src/sound.js        효과음(Web Audio API로 합성)
manifest.webmanifest, sw.js, icons/   앱 설치(PWA)·오프라인 실행
scripts/make-icons.py  앱 아이콘 생성
src/main.js         화면 그리기, 애니메이션, 입력 처리
scripts/build.mjs   단일 HTML 파일 빌드
scripts/curate.mjs  레벨 선별용 탐색 도구
scripts/curate2.mjs 레벨 탐색 도구(색깔 문·여러 조건 지원)
tests/              단위 테스트(unit)·브라우저 테스트(e2e)
```

## 배포

GitHub Pages로 배포됩니다(`.github/workflows/deploy.yml`). 작업 브랜치에 push하면 단위 테스트를 거쳐 자동 배포됩니다.

배포된 사이트를 대상으로 브라우저 테스트를 실행하려면:

```bash
npm run test:live    # https://always-nam.github.io/game_Roblox/ 대상
```
