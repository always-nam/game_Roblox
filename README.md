# 틸트 구슬판 (Tilt Marble Board)

판을 기울여 색 구슬을 같은 색 구멍에 넣는 HTML5/JavaScript 퍼즐 게임입니다. 설치 없이 PC와 모바일 브라우저에서 실행됩니다.

## 규칙

- 판을 **위·아래·왼쪽·오른쪽**으로 기울이면 판 위의 모든 구슬과 돌이 **한꺼번에** 벽이나 다른 조각에 막힐 때까지 굴러갑니다.
- **구슬**은 같은 색 구멍을 지나가는 순간 빠집니다. 다른 색 구멍은 그냥 지나칩니다. 구멍 하나에는 구슬 하나만 들어가고, 채워진 구멍은 평평한 바닥이 됩니다.
- **회색 돌**은 구멍에 빠지지 않아 멈춤판 역할을 합니다. 돌이 **검은 함정**에 들어가면 함정이 메워져 바닥이 됩니다.
- 구슬이 **검은 함정**에 빠지면 실패입니다. 되돌리기로 한 수씩 취소할 수 있습니다.
- 모든 구슬을 구멍에 넣으면 성공입니다. 최소 이동 수(풀이기로 계산)와 비교해 별 1~3개를 받습니다.

16개 단계(1~6단계는 규칙 소개)와 날짜마다 바뀌는 **오늘의 퍼즐**(시드 기반 자동 생성, 풀이 가능 여부를 미리 검증)이 있습니다.

## 조작

| 환경 | 기울이기 | 되돌리기 | 처음부터 |
|---|---|---|---|
| PC | 방향키 또는 WASD | Z / U / Backspace | R |
| 모바일 | 판 위에서 스와이프 | 버튼 | 버튼 |
| 공통 | 화면의 방향 버튼 | 버튼 | 버튼 |

진행 상황(단계별 최고 기록)은 브라우저 `localStorage`에 저장됩니다. 저장이 막힌 환경에서도 게임은 동작합니다.

## 실행

```bash
npm install
npm start            # http://localhost:8080 에서 실행
npm run build        # dist/tilt-marble.html: CSS·JS를 모두 넣은 단일 파일
```

`dist/tilt-marble.html`은 파일을 더블클릭해 바로 열 수도 있습니다.

## 테스트

```bash
npm run test:unit    # 게임 로직·레벨 풀이 가능성·생성기 (Node 내장 테스트)
npm test             # 단위 테스트 + 빌드 + Playwright 브라우저 테스트(데스크톱·모바일)
```

- 단위 테스트는 모든 단계를 너비 우선 탐색 풀이기로 풀어 **풀 수 있는지**와 **최소 이동 수(par)**를 검증합니다.
- 브라우저 테스트는 키보드·방향 버튼·스와이프 입력, 실패/되돌리기, 16단계 전체 클리어, 화면 넘침, 저장소 차단 상황을 확인합니다.

## 구조

```
index.html          화면 구조
style.css           디자인
src/engine.js       순수 게임 로직(기울이기, 승패 판정, 풀이기)
src/levels.js       16개 단계 데이터
src/generator.js    시드 기반 퍼즐 생성기(오늘의 퍼즐)
src/main.js         화면 그리기, 애니메이션, 입력 처리
scripts/build.mjs   단일 HTML 파일 빌드
scripts/curate.mjs  레벨 선별용 탐색 도구
tests/              단위 테스트(unit)·브라우저 테스트(e2e)
```

## 배포

정적 파일만으로 동작하므로 GitHub Pages, Netlify, Vercel 등 어느 정적 호스팅에도 그대로 올릴 수 있습니다. 현재 저장소에는 배포 설정이 연결되어 있지 않습니다.
